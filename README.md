# Essai du navigateur

Une page minuscule qui dit ce que le navigateur d'un appareil sait faire : fonctionner sans Internet, garder des données, parler à un port série, en Bluetooth ou en USB.

- Elle n'envoie rien : elle ne charge que ses propres fichiers, et sa règle de sécurité interdit tout échange avec un autre hôte.
- Elle ne contient aucune donnée.
- Le bouton « Écrire une ligne » écrit une date dans la mémoire de l'appareil ; le bouton « Copier le résultat » copie le relevé, que l'on colle soi-même où l'on veut.

## Mode d'emploi
1. Ouvrir la page dans Chrome (Android) ou Safari (iPad).
2. L'ajouter à l'écran d'accueil, puis la rouvrir depuis l'icône.
3. Appuyer trois fois sur « Écrire une ligne », fermer la page, la rouvrir : le nombre de lignes doit être le même.
4. Passer en mode avion, rouvrir depuis l'icône : la page doit s'afficher.
5. Appuyer sur « Copier le résultat » et coller le texte dans un message.
